# KISA Ecommerce

Интернет-магазин KISA: React + TypeScript + Vite, Django REST API, PostgreSQL и Redis.

- `kisa-brend/` — фронтенд.
- `kisa_brend_back/` — бэкенд, админка, миграции и тесты.
- `deploy/` и `compose.yml` — общий запуск на домене с HTTPS.

Инструкция развёртывания и локального запуска: [DEPLOY.md](DEPLOY.md).

Перед запуском скопируйте `.env.example` в `.env` и установите собственные секреты. Файлы `.env`, зависимости и локальные данные не публикуются в репозитории.
