# KISA — запуск на kisa.deo-core.codes

Требования: сервер с Docker Compose, DNS-запись A для kisa.deo-core.codes на IP сервера, открытые порты 80 и 443. Если есть AAAA, она также должна указывать на этот сервер.

1. Скопировать обе папки проекта вместе с compose.yml и deploy/ на сервер.
2. Скопировать .env.example в .env, заменить оба секрета случайными значениями (пароль PostgreSQL — буквами и цифрами).
3. Запустить из общей папки: `docker compose up -d --build`.
4. Создать администратора: `docker compose exec backend python manage.py createsuperuser`.
5. В https://kisa.deo-core.codes/admin/ заполнить товары, цвета, размеры, остатки, тексты, новости и контакты. Каталог не подменяется демонстрационными товарами. Подписки сохраняются в разделе «Подписчики»; отправка рассылок требует отдельного почтового сервиса. Онлайн-эквайринг не подключён: оформление создаёт заказ для менеджера.

Caddy получает и продлевает сертификат автоматически. Фронтенд работает на /, Django API на /api/, админка на /admin/. База данных и API не открывают порты наружу. Медиа и база хранятся в постоянных томах. Перед обновлением делайте резервную копию PostgreSQL и media_data. Не запускайте `docker compose down -v`: это удаляет данные.

Проверка: открыть каталог и карточку товара, оформить тестовый заказ и проверить его номер, сумму в сомах и резерв в админке. Проверить прямое открытие /catalog и загрузку фотографий.

Локально: фронтенд `npm ci` и `npm run dev`; бэкенд — Python 3.14, зависимости из requirements.txt, `python manage.py migrate`, `CACHE_BACKEND=local python manage.py runserver`. Vite направляет /api/ и /media/ в Django на порту 8000.
